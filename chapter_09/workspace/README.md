# Field Notes

Field Notes is a small command-line tool for keeping research notes in plain
text files.

## Installation

Install it with pip:

```bash
pip install field-notes
```

## Usage

Create a note:

```bash
notes add "Interview with the logistics team"
```

List the notes from the last seven days:

```bash
notes list --days 7
```

Search every note for a word or phrase:

```bash
notes search "delivery times"
```
